# BreadBlade

Считает нож-ролик для лаваша по размерам лаваша и выдаёт **трафарет лезвия для резки из листа стали** (DXF/SVG 1:1).

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # статическая сборка в dist/
```

## Как это считается

- Ролик катится по тесту режущими кромками. Длина окружности по кромке = `N · (длина лаваша + зазор)`,
  где `N` — сколько лавашей вырезается за оборот.
- Контур лаваша (x — по ходу прокатки, y — вдоль оси) переносится на ролик: `φ = x / R_кромки`.
- Лезвие — полоса стали, стоящая на ролике радиально: от дна паза до кромки. Эта поверхность в общем
  случае неразвёртываема, поэтому она раскладывается на плоскость полосой треугольников с точным
  сохранением длины кромки, длины нижнего края и высоты полосы. Небольшое кручение сталь принимает при монтаже.
- Половина овала на ролике проходит почти полный оборот, поэтому её развёртка похожа на шайбу и налезает
  сама на себя. В режиме «Авто» выбирается минимальное число частей (1/2/4/8), при котором развёртка не перекрывается.

## Структура

| Файл | Что делает |
| --- | --- |
| `src/params.ts` | параметры, значения по умолчанию, ссылка с параметрами и localStorage |
| `src/geometry/contour.ts` | контур лаваша: овал/суперэллипс, прямоугольник со скруглением, свой сплайн |
| `src/geometry/layout.ts` | радиусы ролика, раскладка лавашей, предупреждения |
| `src/geometry/develop.ts` | развёртка лезвия и раскладка частей на листе |
| `src/export/drawings.ts` | чертежи трафарета и шаблона ролика, экспорт в SVG и DXF (R12) |
| `src/export/print.ts` | печать 1:1 на листах A4 с перекрытием и схемой склейки |
| `src/scene/viewer.ts` | 3D: изгиб «плоско ↔ ролик», прокатка, экспорт в STL |
| `src/ui/*` | редактор контура, зум чертежей |

Слои DXF: `CUT` — рез, `MARK` — гравировка (граница паза, метки совмещения), `NOTES`/`FRAME` — подписи.
